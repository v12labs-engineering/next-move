# India job feed options

Checked November 16, 2026. The catalog targets software roles that can match candidates with at least two years of experience, across Indian cities and remote roles open to India. This check used first-party provider material and a bounded public read. Credentialed coverage and production rights require evaluation with each provider.

## Direct employer feeds and discovery

The local catalog has 48 enabled employer feeds, with 30 Greenhouse, 10 Lever, seven Ashby, and one Workable. Arbeitnow is also enabled. The same catalog supports SmartRecruiters, Workday career sites, and Recruitee. This gives us reusable adapters across employers. We need a growing directory of verified career boards with India openings, including boards for international employers hiring in India. [Local India seed](../../deploy/local/india-sources.sql) · [Catalog adapters](../../lib/server/catalog/feeds.ts) · [Extended adapters](../../lib/server/catalog/additional-ats.ts) · [Public ATS adapters](../../lib/server/catalog/public-ats.ts)

Chayan publishes links to 561 employer career sites and ATS boards for India tech roles, checked by its publisher on November 5. The links can help identify boards to validate directly. Treat the directory’s reported job counts as a dated observation. The catalog already supports candidate discovery and validation from pinned public directories and Common Crawl. After a board is verified, an individual employer board can provide current jobs and apply links. Custom career sites are candidates for targeted readers that consume permitted sitemaps and `JobPosting` structured data where available. Use the employer’s own publication date when the source supplies it. [Chayan directory](https://getchayan.com/career-pages-of-companies-in-india/) · [Existing source discovery](../source-discovery.md) · [Google JobPosting documentation](https://developers.google.com/search/docs/appearance/structured-data/job-posting)

A read-only pass through the catalog’s URL recognizer found 438 unique supported-format candidates among the 561 rows. It found 185 Workday, 140 Greenhouse, 50 Ashby, 34 Lever, 28 SmartRecruiters, and one Workable candidate. Adobe and BrowserStack Workday validation probes received HTTP 429 and were deferred. The candidate count measures recognizable links. Current India job counts require completed feed reads. [Chayan directory](https://getchayan.com/career-pages-of-companies-in-india/) · [Board URL recognizer](../../lib/server/catalog/source-identity.ts) · [Feed validation](../../lib/server/catalog/discovery/validate.ts)

Wipro’s sampled Bengaluru job detail returned HTTP 200 with `JobPosting` microdata and a visible posting start date. The bounded read of its India careers list did not provide discoverable detail links. For this site, detail parsing looks feasible and list discovery still needs verification. [Wipro posting](https://careers.wipro.com/job/Bengaluru-DEVELOPER-L4-IND-560035/208485-en_US/) · [Wipro India careers](https://careers.wipro.com/go/India/9649255/)

Keep the hourly cron and spread requests by source due time. Hourly checks can serve active, cheap employer feeds, with slower checks for quiet, expensive, or throttled feeds. The scheduled workflow currently selects due boards using the shared freshness window. The separate source-task migration supplies per-source cadence fields, so a uniform hourly cron alone does not implement this policy. Track new unique employer requisitions by city, confirmed application availability, and original posting age to tune each interval. ## Aggregated feeds and API boundaries

| Source | Verified access | Fit for this portal |
| --- | --- | --- |
| Jooble India | India-specific key and REST search. The free allowance is 100 requests per UTC day per country key. [India API signup](https://in.jooble.org/api/about) · [API documentation](https://help.jooble.org/en/support/solutions/articles/60001448238) | Around four requests per hour if spread evenly, before pagination or retries. Search results provide snippets, Jooble job links and an update timestamp. These can support discovery within the API terms. Derive an employer publication date only from the original posting. |
| Adzuna | Official OpenAPI includes `in` for its credentialed job-search endpoint. [OpenAPI](https://developer.adzuna.com/swagger/spec/test2.json) · [Search documentation](https://developer.adzuna.com/docs/search) | Commercial evaluation lasts 14 days. Ongoing use in a revenue- or lead-generating product needs a licence and displayed adverts require attribution. [API terms](https://developer.adzuna.com/docs/terms_of_service) |
| Jobvetta | India-only job search and detail API that says it collects from official employer sources. The free allowance is 50 requests per UTC day shared by REST and MCP. Search returns up to ten jobs. [API documentation](https://www.jobvetta.com/api) | Its terms prohibit bulk download and republication. Treat it as an individual search interface unless the provider expressly approves portal use. [Terms](https://www.jobvetta.com/terms) |
| Headcount Labs | Offers a keyed India filter and a changes endpoint. It reports daily source checks and gives 100,000 returned records per UTC month free. [India coverage](https://headcountlabs.com/countries/india/) · [Developer overview](https://headcountlabs.com/developers/) · [API reference](https://headcountlabs.com/docs/openapi-reference/) | Useful as evidence that a multi-employer career-site feed exists. The project’s earlier decision was to build the direct collector. Provider data uses attribution and ODbL share-alike on published derivative databases. Employer descriptions have separate rights. [Provider licence](https://headcountlabs.com/license/) · [Previous project decision](headcount-labs-source-assessment.md) |
| National Career Service | Government job portal serves private and public jobs. Published materials describe partnerships, vacancy publication through partner API integrations, and data sharing with government partners. [Ministry update](https://www.pib.gov.in/PressReleasePage.aspx?PRID=2294658&lang=1&reg=3) · [Partnership example](https://dge.gov.in/dge/sites/default/files/2025-02/NCS_E-Newsletter_October_2024.pdf) | Public redistribution API could not be verified. Treat direct programmatic access as a partnership inquiry. |
| LinkedIn, Indeed, and Naukri | LinkedIn publishes an authorized partner API for posting jobs. Indeed documents employer job management and a job-search MCP beta for the Claude connector only. Naukri parent Info Edge documents an integration for its hiring suite. [LinkedIn API](https://learn.microsoft.com/en-us/linkedin/talent/job-postings/api/overview) · [Indeed APIs](https://docs.indeed.com/api-guides) · [Indeed MCP](https://docs.indeed.com/mcp) · [Info Edge annual report](https://www.infoedge.in/pdfs/Report_filings/InfoEdge_Annual_Report_2025.pdf) | A general India catalogue export could not be verified for these three. The known interfaces serve separate use cases. |
| Himalayas | Public remote job search across countries, with seniority filters and optional free key. [API docs](https://himalayas.app/docs/remote-jobs-api) | Optional remote source. The published feed refreshes daily, dates in `pubDate` are update dates, and the terms require source credit and use of the Himalayas application link. |
| Remotive and Remote OK | Both publish public remote feeds. [Remotive API](https://remotive.com/remote-jobs/api) · [Remote OK FAQ](https://remoteok.com/faq) | Remote supplements with link-back and attribution requirements. Remotive delays public listings by 24 hours and prohibits using its data behind a sign-up gate. Filter for India eligibility and retain feed provenance. |

## Public endpoint check

The unauthenticated [Himalayas India search](https://himalayas.app/jobs/api/search?q=software%20engineer&country=IN&exclude_worldwide=true&sort=recent) returned HTTP 200, a `totalCount` of 1,202 and 20 first-page rows. The inspected postings explicitly allowed India, including India-only and Asia-Pacific roles. Live `locationRestrictions` entries were country-name strings in those rows. The provider count reflects its keyword search, which also returned technical support roles. It measures neither original publication age nor a match count for candidates with two years of experience. The checked application link used the Himalayas host. [Response contract and terms](https://himalayas.app/docs/remote-jobs-api)

The candidates for a wider local pilot are a larger set of verified employer boards, plus targeted custom career-site adapters for employers with current India software demand. A supplemental aggregator can be judged on incremental employer coverage, duplicate rate, original publication dates, and its terms for the intended user experience.
